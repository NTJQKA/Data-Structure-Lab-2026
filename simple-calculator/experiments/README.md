# 实验与参考代码

本目录保存有参考价值的早期原型，用于回顾实现思路、比较不同方案。代码可能不完整或包含已知问题，不参与主程序的构建。

## 手动分词原型

`calculator_without_tokenizer.cpp` 是早期未使用独立分词头文件的实现，保留原始逻辑供参考。

- 包含整数分词、运算符识别、优先级表和双栈求值框架。
- `solve()` 尚未完成，`main()` 仅对 `8-5=` 分词并输出 `8 - 5 =`。
- 不具备完整的小数、空白字符及非法输入处理，不能作为完整计算器使用。
- 文件包含独立的 `main()`，如需运行应单独编译，不要与主程序一起链接。

当前程序入口见 [`main.cpp`](../main.cpp)，求值实现见 [`Calculator.cpp`](../Calculator.cpp)，分词实现见 [`Tokenizer.h`](../Tokenizer.h)。
