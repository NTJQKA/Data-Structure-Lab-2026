# Simple Calculator

2026 年数据结构实验课第一次实验：**A Simple Calculator**。

本项目使用 C++ 实现表达式求值，重点练习栈的逻辑结构、存储结构和基本操作，以及运算符优先级在表达式计算中的应用。实验要求依据课程课件《project1实验内容》整理。

> 当前项目的主要计算逻辑已实现，包括分词、双栈求值和各运算符的计算。项目仍处于开发阶段，语法错误检测、UI 界面及系统的软件测试尚未完成。

## 实验目标

- 掌握栈的入栈、出栈、访问栈顶等基本操作。
- 使用操作数栈和运算符栈处理表达式，理解栈内、栈外优先级的作用。
- 熟悉 C++ 程序的编辑、编译、链接、运行与调试过程。

## 功能要求

1. 提供友好的用户界面及简单的使用说明。
2. 从键盘读取表达式，以 `=` 作为结束标记。
3. 支持整数、小数、括号，以及以下运算。
4. 计算表达式并输出结果，对非法输入给出提示。

| 符号 | 运算或作用 |
| --- | --- |
| `+`、`-` | 加、减 |
| `*`、`/` | 乘、除 |
| `%` | 求模 |
| `^` | 乘方 |
| `&` | 开方 |
| `(`、`)` | 改变运算顺序 |
| `=` | 表达式结束标记 |

课件中的示例表达式如下，括号统一写为英文半角形式：

```text
-2*3^5 + 23/(45+67) - 17%3/8&2 =
```

这里的 `^` 和 `&` 是计算器表达式中定义的乘方、开方符号。当前 `calculate()` 使用 `pow(x, y)` 计算 `x^y`，使用 `pow(x, 1 / y)` 计算 `x&y`（对 `x` 开 `y` 次方）。

## 实现思路

使用两个栈分别保存操作数和运算符：

- **操作数栈 `sta_x`**：保存读入的数值及中间计算结果，对应课件中的 `opnd`。
- **运算符栈 `sta_op`**：保存尚未完成计算的运算符，对应课件中的 `optr`。

`tokenizer()` 先将表达式拆分为数字和符号，`tool()` 再处理表达式开头及左括号后的负号。`solve()` 从空栈开始依次读取这些 Token。遇到数字时，将其压入操作数栈；遇到运算符时，如果运算符栈非空，则比较栈顶运算符的栈内优先级与当前运算符的栈外优先级：

1. **栈为空或栈内优先级较低**：当前运算符入栈，继续读取下一个符号。
2. **栈内优先级较高**：弹出一个运算符和两个操作数进行计算，将结果入栈，然后继续处理当前运算符。注意先弹出的是右操作数。
3. **优先级相等**：弹出栈顶运算符，用于匹配左右括号。

末尾的 `=` 触发剩余运算。对于符合要求的表达式，最终操作数栈中只剩一个结果，运算符栈中留下 `=`。当前实现直接输出操作数栈顶，表达式完整性及最终栈状态的校验仍待补充。

### 优先级表

以下数值来自课件，现有代码中的 `lev_in`、`lev_out` 也按此定义。数值越大，优先级越高。

| 运算符 | 栈内优先级 | 栈外优先级 |
| --- | ---: | ---: |
| `=` | 0 | 0 |
| `+`、`-` | 3 | 2 |
| `*`、`/`、`%` | 5 | 4 |
| `(` | 1 | 8 |
| `)` | 8 | 1 |
| `^`、`&` | 7 | 6 |

课件建议将顺序栈或链栈的实现放入头文件。当前代码使用标准库的 `std::stack` 完成求值。


| 文件 | 当前用途 |
| --- | --- |
| `Calculator.cpp` | 主程序，包含优先级表、运算函数 `calculate()`、双栈求值函数 `solve()` 和示例入口 |

`experiments/` 保存有参考价值的原型代码并纳入版本管理。它不参与主程序构建，已知限制见[实验代码说明](experiments/README.md)。完整的修改历史仍可从 Git 提交记录中查看。

## 当前进度

- **主要计算逻辑已实现**：按栈内、栈外优先级完成双栈求值，处理括号，以及加、减、乘、除、求模、乘方和开方。
- **分词及部分负号处理已接入**：识别整数、小数、运算符并跳过空白字符，在表达式开头或左括号后的负号前补零。
- **已有初步错误提示**：分词时检查非法字符及部分小数格式，运算时检查除数、模数是否接近零。
- **语法错误检测未完成**：仍需统一检查括号匹配、操作数数量、运算符位置、数字格式及结束标记，并在输入不合法时安全停止求值。
- **UI 界面未完成**：当前通过 `main()` 中写好的表达式演示，输出分词序列和计算结果，尚未接入键盘输入和完整的使用帮助。
- **软件测试未完成**：已有编译和示例运行验证，尚未完成系统的正常用例、边界条件及异常输入测试。

### 当前限制

- 请使用英文半角符号，表达式末尾需要 `=`，不要用空格拆开一个完整的数。
- 非法表达式可能触发空栈访问或得到错误结果，现阶段应使用格式正确的表达式。
- `%` 当前先将两侧操作数转换为 `int` 再求余，非整数输入的处理规则和转换后的除零检查有待完善。
- 乘方、开方的定义域及非有限结果尚未统一处理，部分输入可能输出 `nan` 或 `inf`。

## 编译与运行

代码使用 C++17 的结构化绑定及标准库头文件。以下以 GCC / MinGW-w64 为例。

在仓库根目录打开 PowerShell，编译并运行主程序：

```powershell
cd simple-calculator
g++ -std=c++17 -Wall -Wextra Calculator.cpp -o Calculator.exe
.\Calculator.exe
```

`Tokenizer.h` 由主程序包含，无需单独编译。当前示例表达式写在 `Calculator.cpp` 的 `main()` 中，修改后需要重新编译。`experiments/` 中的原型有独立的 `main()`，应单独编译，不能与主程序一起链接。

当前示例表达式为：

```text
-2*3^5+23/(45+67)-17%3/8&2=
```

程序先输出处理后的分词序列，再输出计算结果：

```text
0 - 2 * 3 ^ 5 + 23 / ( 45 + 67 ) - 17 % 3 / 8 & 2 =
-486.502
```

结果使用默认输出精度，显示值经过舍入。此示例已编译运行验证，不代表完整的软件测试已经完成。
