# Simple Calculator

2026 年数据结构实验课第一次实验：**A Simple Calculator**。

本项目使用 C++ 实现表达式求值，重点练习栈的逻辑结构、存储结构和基本操作，以及运算符优先级在表达式计算中的应用。实验要求依据课程课件《project1实验内容》整理。

> 当前项目处于开发阶段，已包含分词代码和双栈求值框架，尚未完成完整的计算器功能。

## 实验目标

- 掌握栈的入栈、出栈、访问栈顶等基本操作。
- 使用操作数栈和运算符栈处理表达式，理解栈内、栈外优先级的作用。
- 熟悉 C++ 程序的编辑、编译、链接、运行与调试过程。

## 功能要求

1. 提供友好的用户界面及简单的使用说明。
2. 从键盘读取表达式，以 `=` 作为结束标记。
3. 支持整数、小数、括号，以及以下运算。
4. 计算表达式并输出结果，对非法输入给出提示。

| 符号 | 运算或作用 |
| --- | --- |
| `+`、`-` | 加、减 |
| `*`、`/` | 乘、除 |
| `%` | 求模 |
| `^` | 乘方 |
| `&` | 开方 |
| `(`、`)` | 改变运算顺序 |
| `=` | 表达式结束标记 |

课件中的示例表达式如下，括号统一写为英文半角形式：

```text
-2*3^5 + 23/(45+67) - 17%3/8&2 =
```

这里的 `^` 和 `&` 是计算器表达式中定义的乘方、开方符号，具体计算需要在求值函数中实现。

## 实现思路

使用两个栈分别保存操作数和运算符：

- **操作数栈 `opnd`**：保存读入的数值及中间计算结果。
- **运算符栈 `optr`**：保存尚未完成计算的运算符。

先将 `=` 放入运算符栈，再依次读取表达式中的数字和符号。遇到数字时，将其压入操作数栈；遇到运算符时，比较栈顶运算符的栈内优先级与当前运算符的栈外优先级：

1. **栈内优先级较低**：当前运算符入栈，继续读取下一个符号。
2. **栈内优先级较高**：弹出一个运算符和两个操作数进行计算，将结果入栈，然后继续处理当前运算符。注意先弹出的是右操作数。
3. **优先级相等**：弹出栈顶运算符，用于匹配括号或结束标记。

结束时检查表达式是否完整，操作数栈中应只剩一个最终结果。课件还建议处理表达式开头及左括号后的正负号。

### 优先级表

以下数值来自课件，现有代码中的 `lev_in`、`lev_out` 也按此定义。数值越大，优先级越高。

| 运算符 | 栈内优先级 | 栈外优先级 |
| --- | ---: | ---: |
| `=` | 0 | 0 |
| `+`、`-` | 3 | 2 |
| `*`、`/`、`%` | 5 | 4 |
| `(` | 1 | 8 |
| `)` | 8 | 1 |
| `^`、`&` | 7 | 6 |

课件建议将顺序栈或链栈的实现放入头文件。当前代码暂时使用标准库的 `std::stack` 搭建框架。

## 编译与运行

代码使用 C++17 的结构化绑定，并包含 GCC 的 `<bits/stdc++.h>`。可使用支持 C++17 的 GCC / MinGW-w64 编译。

在仓库根目录打开 PowerShell，分别编译两个版本：

```powershell
cd "Simple Calculator"
g++ -std=c++17 -Wall -Wextra cal.cpp -o cal.exe
g++ -std=c++17 -Wall -Wextra cal_with_lu.cpp -o cal_with_lu.exe

.\cal.exe
.\cal_with_lu.exe
```

两个 `.cpp` 文件各自包含 `main()`，需分别编译。当前示例表达式写在各自的 `main()` 中，修改后需要重新编译。

`cal.cpp` 当前对 `8-5=` 分词，输出：

```text
8 - 5 =
```

`cal_with_lu.cpp` 当前最终打印 `-(3.15+5.55)=` 的分词结果：

```text
- ( 3.15 + 5.55 ) =
```

以上输出仅展示分词结果，表达式的数值计算仍待实现。
